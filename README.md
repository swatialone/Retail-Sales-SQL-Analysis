# Retail Sales SQL Analysis

## Project Overview

This project analyzes retail sales data using MySQL. SQL queries were written to answer business questions and generate meaningful insights from the dataset.

---

## Tools Used

- MySQL
- MySQL Workbench

---

## Dataset

Retail Sales Dataset

---

## SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- COUNT()
- SUM()
- AVG()
- DISTINCT
- DATE_FORMAT()
- CASE
- Aggregate Functions

---

## Business Questions Solved

1. Total number of records
2. Number of unique customers
3. Unique product categories
4. Null value checking
5. Sales on a specific date
6. Clothing sales in November 2022
7. Total sales by category
8. Average customer age for Beauty category
9. Transactions where total sales exceed 1000
10. Orders by gender and category
